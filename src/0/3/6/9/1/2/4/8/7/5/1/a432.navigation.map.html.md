# A432 Navigation Map HTML Visualization Documentation

## Overview

The `a432.navigation.map.html` file provides an interactive visualization of the A432 Multidimensional Navigation Map. This HTML interface allows users to explore the sequence `/0\3\6\9/1\2\4\8/7/5/1\` through an animated spiral visualization and real-time navigation controls.

## Features

### Interactive Spiral Visualization
- **Canvas-based rendering** of the navigation spiral
- **Real-time animation** of navigation progression
- **Color-coded points** for different navigation states
- **Dynamic labeling** of navigation parts
- **Responsive design** for different screen sizes

### Navigation Controls
- **Navigate Next**: Progress to next position in sequence
- **Complete Cycle**: Animate through entire 11-position cycle
- **Reset**: Return to initial state

### Real-time Status Display
- **Current Part**: Active navigation sector
- **Spiral Level**: Current elevation in spiral
- **Consciousness**: Current consciousness type
- **Next Decision**: Required choice at next gateway
- **Total Navigations**: Cumulative navigation count

### Core Functions

#### navigateNext()
Advances to next position in sequence:
```javascript
function navigateNext() {
  const currentIndex = currentState.totalNavigations % sequence.length;
  const nextIndex = (currentIndex + 1) % sequence.length;
  
  currentState.currentPart = partNames[nextIndex];
  currentState.spiralLevel = Math.floor(currentState.totalNavigations / sequence.length) + 1;
  currentState.consciousness = `${partNames[nextIndex]} consciousness (Spiral ${currentState.spiralLevel})`;
  currentState.nextDecision = decisions[nextIndex];
  currentState.totalNavigations++;
  
  updateDisplay();
  drawSpiral();
}
```

#### navigateCycle()
Animates through complete cycle:
```javascript
function navigateCycle() {
  for (let i = 0; i < sequence.length; i++) {
    setTimeout(() => {
      navigateNext();
    }, i * 500);
  }
}
```

#### drawSpiral()
Renders spiral visualization:
```javascript
function drawSpiral() {
  const canvas = document.getElementById('spiralCanvas');
  const ctx = canvas.getContext('2d');
  
  // Set canvas size
  canvas.width = canvas.offsetWidth;
  canvas.height = canvas.offsetHeight;
  
  const centerX = canvas.width / 2;
  const centerY = canvas.height / 2;
  
  // Clear canvas
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  
  // Draw spiral
  ctx.strokeStyle = '#4ecdc4';
  ctx.lineWidth = 2;
  ctx.beginPath();
  
  for (let i = 0; i < currentState.totalNavigations + 1; i++) {
    const angle = i * 0.5;
    const radius = i * 3;
    const x = centerX + radius * Math.cos(angle);
    const y = centerY + radius * Math.sin(angle);
    
    if (i === 0) {
      ctx.moveTo(x, y);
    } else {
      ctx.lineTo(x, y);
    }
    
    // Draw points
    ctx.fillStyle = i === currentState.totalNavigations ? '#ff6b6b' : '#4ecdc4';
    ctx.beginPath();
    ctx.arc(x, y, 5, 0, 2 * Math.PI);
    ctx.fill();
    
    // Label points
    if (i < partNames.length) {
      ctx.fillStyle = '#fff';
      ctx.font = '12px Arial';
      ctx.fillText(partNames[i % partNames.length], x + 10, y);
    }
  }
  
  ctx.stroke();
}
```
